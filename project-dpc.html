3D 打印成本计算器

离线单文件报价工具 · 网页 / Windows / Android 三端

完全离线 数据不出设备 单文件 · 零依赖 MIT 开源

源码与更新： github.com/steveliuyan/3d-print-cost-cn

应用预览

3D 打印成本计算器 · 本地离线运行

功能亮点

成本核算

材料、设备折旧、电费、人工后处理、失败率摊销，一笔笔算清单件成本。

订单化报价

多品项订单行项管理，抬头编号 / 客户 / 报价有效期 / 订单状态，支持阶梯定价与整单折扣。

客户版 / 内部版分享长图

一键生成报价长图：客户版自动隐藏成本与利润、仅呈现报价，内部版保留完整成本与毛利率。

STL / 3MF 导入估算

导入模型文件自动估算耗材与打印时长，支持读取切片 3MF 中的实测用量。

定价反推

按平台佣金率反推挂牌价，目标毛利率、单件利润一目了然。

内置预设

11 个设备 + 54 个材料预设（拓竹 / 大简 / 三慈 / 通用），支持自定义增删改。

备份恢复

参数 / 预设 / 分类全量备份与恢复，数据永远在你自己手里。

离线可用

不联网、不上传任何数据，单文件双击即用，随时随地报价。
